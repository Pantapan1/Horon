  VOXELHORIZON RUST ENGINE v6.0 (RUST NDK + OPENGL ES + LUAJ)
  Нативное ядро на Rust (ARM64/ARMv7 .so) — максимальный FPS без лагов!

КАК СОБРАТЬ APK В GITHUB (~3-4 МИНУТЫ):
1. Загрузите ВСЕ 35 файлов из архива в корень репозитория GitHub.
2. Обновите .github/workflows/build-apk.yml содержимым файла build-apk.yml.
3. GitHub сам скомпилирует Rust-ядро (libvoxelhorizon_core.so с -O3 и LTO)
   под ARM64, ARMv7 и x86_64 и выложит готовый VoxelHorizon-Rust-v6.0.apk
   прямо в раздел RELEASES!

ЧТО ПЕРЕПИСАНО НА RUST В v6.0 ДЛЯ МАКСИМАЛЬНОГО FPS:
1. ВЕСЬ 250-СЛОЙНЫЙ МИР И ГЕНЕРАЦИЯ (rust_world.rs, rust_noise.rs):
   - Плоские массивы [u8; 16*16*250] без сборщика мусора (GC) и боксинга!
   - 3D-пещеры, глубинный сланец, кристалльные гроты, заброшенные шахты,
     лагерь, данжи, Ад, Эфир и автономные сезоны работают на чистом Rust!
2. УЛЬТРАБЫСТРЫЙ ИЗОМЕТРИЧЕСКИЙ МЕШЕР НА RUST (rust_mesher.rs):
   - Локальный 5x5 кэш указателей на чанки -> 0 обращений к HashMap в кадре!
   - Все видимые грани 250 слоёв, отсечение скрытых граней, тёмный срез
     шахты (без переключения текстур!), прозрачность перед героем, волны
     воды, свет и подсветка руд собираются на Rust в единый DirectByteBuffer!
   - Вместо 15 000 мелких вызовов draw() -> ~50 крупных батчей OpenGL ES
     и 0 байт аллокаций мусора за кадр!
3. ФИЗИКА, СРЕЗ КРЫШИ И 3D-ПИКИНГ БЛОКОВ НА RUST + СЧЁТЧИК FPS:
   - В верхней панели теперь выводится живой счётчик «XX FPS (Rust)».
4. СОХРАНЕНЫ ВСЕ ФИШКИ v5.4:
   - Полный Онлайн-мультиплеер (Код комнаты через Интернет / LAN / IP) с
     синхронизацией мобов, боссов, сундуков, дропа, табличек, чата и PvP.
   - Живые 4-кадровые анимации, реалистичный сон на кровати (x2.6),
     управление Стик + Тапы, все 30 мобов, 5 боссов, Наковальня и LuaJ-моды!
