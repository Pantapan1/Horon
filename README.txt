================================================================
  VOXELHORIZON NATIVE v4.0 (KOTLIN + OPENGL ES / LIBGDX + LUAJ)
  Плоский архив без папок — нативный Android APK без WebView!
================================================================

КАК СОБРАТЬ НАТИВНЫЙ APK В GITHUB ЗА 2-3 МИНУТЫ:
1. Создайте новый (или очистите старый) репозиторий на GitHub.
2. Загрузите ВСЕ файлы из этого архива прямо в корень репозитория
   (все .kt файлы, settings.gradle, build.gradle, app_build.gradle,
   AndroidManifest.xml, font.ttf, icon.png, cover_anime.jpg, anime_tiles.png,
   ost_*.wav, README.txt).
3. Создайте файл .github/workflows/build-apk.yml и вставьте туда
   содержимое файла build-apk.yml из этого архива -> Commit!
4. Во вкладке Actions запустится «Build VoxelHorizon Native v4.0 APK».
   Скрипт сам разложит файлы по папкам Android/libGDX, скомпилирует
   нативный Kotlin + OpenGL ES + LuaJ и выложит чистый
   «VoxelHorizon-Native-v4.0.apk» прямо в раздел RELEASES (без .zip)!

ЧТО ВНУТРИ НАТИВНОГО ДВИЖКА v4.0:
- 100% нативный Kotlin + libGDX (OpenGL ES) без браузера и WebView!
- Многопоточная генерация чанков (2D/3D шум Перлина, 6 биомов, пещеры,
  нативные Данжи-башни с сундуками, Ад / Nether и Небесные Острова / Эфир).
- Свой GLSL-шейдер: Ambient Occlusion (AO), 2-канальный свет (небо + блоки),
  динамический свет от факела в главной/второй руке, волны и блики на воде,
  покачивание листвы на ветру и мгновенная GPU-смена сезонов!
- 3D-пропсы (анимированные сундуки, 2-блочные кровати, мерцающие факелы),
  14 3D-мобов + 2 Босса + 3D Питомец-Лис + 6 аниме 3D-скинов.
- Вторая рука (Off-hand), Рывок (Dash), Катана, Молот AoE, Лук, Крюк-кошка,
  Элитры (планер), реалистичная рубка деревьев и осыпание песка/гравия.
- Встроенный интерпретатор Lua (LuaJ) с Хабом Модов в настройках,
  поддержкой .lua / .vhpack из папки VoxelHorizon/mods/ и Hot Reload!
- Нативный мультиплеер (TCP + UDP автопоиск по LAN Wi-Fi + прямой IP),
  Bluetooth-геймпады, бинарные GZIP-сохранения миров и стерео-саундтрек!
