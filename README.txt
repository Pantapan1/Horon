--- ЧАСТЬ 1: v6.10 (OPEN MOD ENGINE + ВЕРСИИ МОДОВ) ---

========================================================================
  VOXELHORIZON RUST ENGINE v6.10 — OPEN MOD ENGINE (ПОЛНАЯ СВОБОДА МОДАМ!)
========================================================================

ЧТО НОВОГО В v6.10:
1. ВЕРСИОНИРОВАННЫЙ МЕНЕДЖЕР МОДОВ (БЕЗ ДУБЛЕЙ ПРИ ОБНОВЛЕНИИ):
   - Каждый .vhpack читает manifest.json (id, name, version, author, description).
   - При установке новой версии (например Music_v2.vhpack поверх v1.0) игра
     находит старый пакет по id, обновляет его на месте и пишет «Обновлён: v1.0 -> v2.0»!
   - В Настройках -> Моды отображается версия мода, сохраняется статус ВКЛ/ВЫКЛ,
     есть кнопки «Подел.» (отправить другу) и «Удал.» (полное удаление мода и его рецептов).
   - Рецепты и правила из .vhmod больше не дублируются при повторном импорте!
2. ПОЛНЫЙ БЕЗГРАНИЧНЫЙ ДОСТУП ДЛЯ МОДОВ (LuaModEngine + ModAudioEngine + VH.engine):
   - VH.registerBlockEx / VH.registerItem / VH.registerRecipe / VH.loadTexture:
     моды могут загружать свои 64x64 PNG-текстуры, 3D-пропы (isProp=true),
     светящиеся блоки, оружие, инструменты и крафты прямо изнутри .vhpack!
   - VH.ui.*: полноценный конструктор собственных экранов (окна, панели, кнопки,
     интерактивные зоны, иконки, прогресс-бары, ввод текста с клавиатуры Android)!
   - VH.audio.*: встроенный 22050 Гц PCM-синтезатор и 4-канальный секвенсор
     (Пила/Квадрат/Синус/Шум, VU-метры, фоновая музыка в мире)!
   - Все хуки движка: onLoad, onTick, onRenderHud, onRenderScreen, onBlockBreak,
     onBlockPlace, onBlockInteract, onItemUse, onMobKill, onPlayerDamage, onChat, onFileImport!
   - VH.engine.* + luajava: прямой неограниченный доступ к живому коду игры
     (game, world, player, entities, registry, sprites, net, profiles, redstone, platform)!
